# Certificates Directory

Save your certificate image or PDF files here. The portfolio website will automatically load and display them when a visitor clicks on any certificate card.

### Supported File Names:
- `pl900.png` (or `.jpg` / `.jpeg` / `.webp` / `.pdf`) → Microsoft Certified: Power Platform Fundamentals (PL-900)
- `ibm-python.png` (or `.jpg` / `.jpeg` / `.webp` / `.pdf`) → IBM: Python for Data Science & AI
- `iot.png` (or `.jpg` / `.jpeg` / `.webp` / `.pdf`) → IoT Workshop (SVL Automation)
- `diploma.png` (or `.jpg` / `.jpeg` / `.webp` / `.pdf`) → Smart Diploma Foundation Course
- `shark-tank.png` (or `.jpg` / `.jpeg` / `.webp` / `.pdf`) → Shark Tank Innovation Event

Whenever you add or update any file here, the website will display the actual certificate scan immediately!
